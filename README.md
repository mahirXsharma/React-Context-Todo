# 📝 React Todo App (Context API + Local Storage)

A robust task management application built with **React**. This project demonstrates advanced state management using the **Context API** and data persistence with **Local Storage**, ensuring your tasks remain safe even after refreshing the page.

## 🚀 Features

- **Add & Delete Todos**: Full CRUD functionality.
- **Edit Mode**: Update existing tasks inline with a toggleable UI.
- **Data Persistence**: Uses Local Storage to save tasks automatically.
- **State Management**: Centralized logic using React Context API.
- **Responsive Design**: Clean UI based on Tailwind CSS concepts.

## 🛠️ Tech Stack

- **React.js** (Vite)
- **Context API** (State Management)
- **Local Storage** (Browser Database)
- **JavaScript** (ES6+)
- **CSS / Tailwind**

## ⚙️ How to Run Locally

1. Clone the repository:
   ```bash
   git clone [https://github.com/mahirXsharma/React-Context-Todo.git](https://github.com/mahirXsharma/React-Context-Todo.git)
   ```

2. Navigate to the project folder:
   ```bash
   cd React-Context-Todo
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## 🧠 What I Learned

Building this project helped solidify several core React concepts:
- **Avoiding Prop Drilling**: Used Context API to manage global state effectively.
- **useEffect Hooks**: Mastered the order of operations for loading vs. saving data to Local Storage to prevent race conditions.
- **Complex State Logic**: Managed "Edit Mode" toggles and specific ID targeting for updates.
